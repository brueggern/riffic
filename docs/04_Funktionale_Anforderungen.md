# 04 Funktionale Anforderungen

Gruppiert nach Funktionsbereichen. Priorität: Muss / Soll / Kann.

## Aufnahme

- **FA-001** (Muss) Der Benutzer kann direkt vom Startbildschirm eine neue Audio-Aufnahme starten.
- **FA-002** (Muss) Der Benutzer kann eine laufende Aufnahme beenden; die Aufnahme wird gespeichert.

## Verwaltung von Einträgen

- **FA-003** (Muss) Nach der Aufnahme kann der Benutzer der Aufnahme einen Titel geben.
- **FA-004** (Muss) Nach der Aufnahme kann der Benutzer optional Notizen hinzufügen.

## Gruppierung

- **FA-005** (Soll) Der Benutzer kann Aufnahmen taggen oder gruppieren.

## Offene Fragen

- FA-003: Ist der Titel Pflicht oder wird ein Standardtitel (z. B. Datum/Uhrzeit) vergeben, wenn keiner eingegeben wird?
- FA-005: Tags (mehrere pro Aufnahme), Gruppen/Ordner (genau eine pro Aufnahme) oder beides?
